# Railway Ticket Booking System

## About

This is a simple Railway Ticket Booking System created using Core Java. The project allows a user to enter passenger details, select a train, choose a seat type, enter the number of tickets, and generate the final bill.

While building this project, I practised Java fundamentals such as classes, objects, constructors, methods, switch-case, user input using Scanner, and basic billing logic.

## Features

* Passenger Details
* Train Selection
* Seat Selection
* Ticket Booking
* Fare Calculation
* GST Calculation
* Discount
* Final Bill

## Technologies Used

* Java
* Core Java
* OOP
* Scanner Class

## How to Run

```bash
javac railwaysTicketBookingSystem.java
java railwaysTicketBookingSystem
```
